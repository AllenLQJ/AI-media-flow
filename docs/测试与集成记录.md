## 运行与交接

本项目用 `uv sync --locked` 安装，执行 `uv run python scripts/fake_demo.py` 可复现模拟闭环。真实 CLI 操作见 README。Hub 启动方式为其环境的 `python -m agent_hub mcp`，该项目的配置和共享后台由 Hub 项目维护。

用户自行将 `docs/HubGateway-v1-服务端实施约定.md` 和 `contracts/` 交给 Hub 项目的聊天。本项目等待能力及服务端验收证据后继续真实联调，不自行重启 Hub 或绕过门禁。
