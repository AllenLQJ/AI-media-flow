# 可调整的风格组织

这些是本项目自写的提示组织方法，参数仍以 Hub 的实际能力为准，不是模型私有语法。

## 写实国风 / 影视 CG

目标是自然面部比例、真实体积、皮肤微细纹理、发丝、衣料和金属的可信材质、连续光影与场景纵深。角色仍为原创成年人，不沿用其他风格的发色、服装和武器设定。

分开写清：主体与服装、手持物及接触关系、人物在镜头中的位置、前后景、光线来源、冷暖色彩、景深和材质。用“自然面部比例、细发丝、柔和面部补光、冷色轮廓光、薄雾中的远景”代替笼统堆叠“高级/电影感”。

需要接近写实CG时，在普通文本中明确排除粗黑漫画描边、大型动画眼、平面赛璐璐色块和可见油画笔触。不要添加未验证的 negative_prompt、权重、seed 或尺寸字段。

## 平面动画 / 赛璐璐

目标是清晰描线、统一线宽、有限阴影层次、明确色块分界及稳定角色设定。不要同时要求写实皮肤毛孔、照片质感与完全平面色块。

## 根据样张反馈调整

先记录具体偏差：画风类别、角色特征、手持关系、构图、场景或光照，再修改相关段落。用户换目标风格时一并重置角色/场景，不只把旧提示词最后加一句新画风。请求与 Skill 内容变化产生新版本，重新审核后才生成；单张通过不证明跨图一致性。
